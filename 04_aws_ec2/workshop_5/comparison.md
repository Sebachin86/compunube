# Hacerlo a mano o usar User Data

| Criterio | Manual | User Data |
|---|---|---|
| Repetir el proceso | Toca hacer los pasos otra vez | Se puede automatizar |
| Tiempo | Depende de quien lo haga | Normalmente toma menos pasos manuales |
| Errores | Es fácil saltarse algo | Reduce pasos, pero igual hay que probarlo |
| Revisar qué pasó | Puede quedar en el historial de la consola | Se puede revisar el script y los logs de cloud-init |

Para prácticas pequeñas User Data ayuda bastante. En proyectos más grandes también se pueden usar herramientas de infraestructura como código.
