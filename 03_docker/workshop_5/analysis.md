# PostgreSQL y MongoDB

PostgreSQL organiza la información en tablas, filas y columnas. MongoDB la guarda en colecciones de documentos BSON. En MongoDB es cómodo guardar datos anidados que se consultan juntos, pero si duplico información puedo terminar con datos diferentes en varios documentos. PostgreSQL ayuda cuando necesito relaciones, reglas e integridad entre tablas. La elección depende de cómo voy a consultar y cuidar los datos.
