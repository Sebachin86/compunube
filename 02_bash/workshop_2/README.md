# Taller 2 — Dockerfile, CMD y ENTRYPOINT

Construyo la imagen con `docker build -t ubuntu-bash-lab .` y la pruebo con `docker run --rm ubuntu-bash-lab`. También puedo pasar `--help` o `--info`. La idea es ver que `ENTRYPOINT` deja fijo el programa que arranca y `CMD` pone los argumentos por defecto.
